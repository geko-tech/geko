# Test

Running `geko test` without arguments tests all Workspace Schemes generated by `AutogeneratedSchemes.workspace`:

```bash
geko test
```

Specify the scheme you want to test:

```bash
geko test MainApp
```

Test a specific module's scheme, for example `Framework2`:

```bash
geko test Framework2
```

## Selecting tests

Specify which tests to run. The list of test identifiers you want to test. The expected format is `TestTarget[/TestClass[/TestMethod]]`:

```bash
geko test MainApp --test-targets Framework2Tests/MyPublicClassTests Framework2Tests/Framework2Tests
```

Specify a test plan:

```bash
geko test MainApp --test-plan GeneratedTestPlan
```

The `--edit-test-plan` flag edits the list of test targets in the test plan (passed via `--test-plan`) and adds the test targets passed via the `--test-targets` argument to that list, or adds all of them if the argument was not passed:

```bash
geko test MainApp --edit-test-plan
```

## Choosing a destination

Pass a build destination directly to `xcodebuild` with the `-destination` flag:

```bash
geko test MainApp -- -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.5'
```
