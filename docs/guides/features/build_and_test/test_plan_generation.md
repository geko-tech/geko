# Test plan generation

## Creating a test plan

Create a test plan in `Workspace.swift` via [`generationOptions.autogeneratedTestPlans`](../../../projectdescription/structs/Workspace.GenerationOptions.md#autogeneratedtestplans) and give it a name:

```swift
generationOptions: .options(
    autogeneratedTestPlans: [
        .testPlan(
            name: "GeneratedTestPlan.xctestplan",
        )
    ]
)
```

## `scheme` parameter

Specifies the scheme into which the generated test plan should be added:

```swift
generationOptions: .options(
    autogeneratedTestPlans: [
        .testPlan(
            name: "GeneratedTestPlan.xctestplan",
            scheme: .init(
                project: "MainApp",
                scheme: "MainApp"
            ),
        )
    ]
)
```

## `path` parameter

The path to the folder where the test plan will be created. If not specified, it is created in `Derived/TestPlans/<name>.xctestplan` of the project:

```swift
generationOptions: .options(
    autogeneratedTestPlans: [
        .testPlan(
            name: "GeneratedTestPlan.xctestplan",
            path: "TestPlans/Geko",
        )
    ]
)
```

## `testTargetSelection` parameter

Specifies which test targets will be added to the test plan. By default all test targets are added:

```swift
generationOptions: .options(
    autogeneratedTestPlans: [
        .testPlan(
            name: "GeneratedTestPlan.xctestplan",
            testTargetSelection: .all,
        )
    ]
)
```

Or you can specify which test targets will be added to the test plan:

```swift
generationOptions: .options(
    autogeneratedTestPlans: [
        .testPlan(
            name: "GeneratedTestPlan.xctestplan",
            testTargetSelection: .specific([
                .target("Framework1Tests"),
                .target("Framework2Tests", selectedTests: ["Framework2Tests/MyPublicClassTests"])
            ])
        )
    ]
)
```

## `configurationOptions` and `defaultOptions` parameters

Allow you to configure the test plan. All available settings can be found in the [AutogeneratedTestPlan.Options](../../../projectdescription/structs/AutogeneratedTestPlan.Options.md) documentation.
