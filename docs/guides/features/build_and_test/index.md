# Build and Test

Geko lets you build and test your project without leaving the command line. It integrates with `xcodebuild` and lets you describe the targets of a scheme with **target selection scopes**, so you can target a single module, a single test, or the whole project with minimal setup.

This section covers:

* [Best practices](./best_practices.md) – recommended workflows for building and testing individual or multiple targets.
* [Build](./build.md) – building schemes, choosing devices, platforms, and configurations.
* [Test](./test.md) – running tests, test targets, and test plans.
* [Targets selection](./targets_selection.md) - describing schemes for your projects and workspaces with `targetSelection` scopes.
* [Test plan generation](./test_plan_generation.md) – generating test plans that reference your test targets.
* [Schemes generation](./schemes_generation.md) – or generating them automatically.
